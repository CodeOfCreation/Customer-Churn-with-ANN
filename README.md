Customer Churn Prediction Using Artificial Neural Network (ANN)
📌 Project Overview

Customer Churn Prediction is a Machine Learning project that uses an Artificial Neural Network (ANN) to predict whether a customer is likely to leave a company or continue using its services.

Customer churn is a major challenge for businesses, especially in the banking, telecom, and subscription industries. This project uses customer data to identify potential churners and help businesses make data-driven decisions to improve customer retention.

🎯 Objectives
Predict whether a customer will churn or stay.
Build an Artificial Neural Network (ANN) model.
Perform data preprocessing and feature engineering.
Analyze important customer characteristics.
Evaluate model performance using classification metrics.
